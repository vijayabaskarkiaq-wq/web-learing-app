Study Material

HTML

HTML gives a webpage its structure. Use elements such as headings, paragraphs, links, images, and forms to organize content, and choose semantic elements like <main> and <article> to describe each part clearly.

CSS

CSS controls how HTML content looks and is arranged. Practice selectors, the box model, colors, spacing, Flexbox, and Grid. Media queries help adapt a layout so it remains readable on phones, tablets, and larger screens.

Bootstrap and Tailwind CSS

Bootstrap and Tailwind help build consistent interfaces quickly. Bootstrap provides ready-made components and a responsive grid, while Tailwind uses small utility classes that you combine directly in your markup.

JavaScript

JavaScript adds behavior to webpages. Learn variables, data types, conditions, loops, and functions first, then use events to respond to actions such as clicking a button or submitting a form.

DOM Manipulation

The DOM represents a webpage as objects that JavaScript can read and update. Select elements, change their text or attributes, and add event listeners to make the page respond to user interaction.

APIs and Fetch

An API lets an application exchange data with another service. The Fetch API makes HTTP requests; check whether a response succeeded, convert its body to JSON, and handle errors so users know when data cannot be loaded.
